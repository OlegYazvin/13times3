# Homepage illustrations

The 39 achievement cards each have a distinct image. The last 15 were generated for this site with the built-in image tool and optimized as WebP in `src/assets/media/achievements/`.

## Style prompt

Use `src/assets/media/2a0b85df0e7c8377.png` and `src/assets/media/e0c9d7fcf7266eed.png` as **style references only**. Make a new square illustration for each achievement. Match the existing abstract expressionist 2D paintings: simplified figures and faces, bold painted planes, dark contours, broad visible brushwork, rough paper texture, cream negative space, and sweeping teal, cobalt, turquoise, orange, black, and gold ribbons. The action should read at thumbnail size. Avoid photographic rendering, realistic interiors, 3D effects, tiny decorative objects, text, lettering, numbers, and logos.
