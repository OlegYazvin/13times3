# Scene work in this repository

Before planning or authoring a gallery room, read [docs/scene-registry.md](docs/scene-registry.md) and [docs/scene-guide.md](docs/scene-guide.md).

- Compare the proposed memory or event with every registry entry by people, action, and setting, not just by title. If it overlaps, tell the user which frame already covers it before making another room. Clarify whether they want to revise that scene or show a distinct moment.
- Update the registry in the same change that reserves, publishes, revises, or removes a scene. Keep the title and frame ID aligned with `src/_data/gallery.json`. An unassigned frame is not a completed scene.
- Apply the art, portal, collision, mobile-control, and verification lessons in the scene guide. Future rooms can have different themes; the undersea cave belongs to frame 01.
- Preserve all 39 original achievement URLs and the 41 stable gallery frame IDs.
